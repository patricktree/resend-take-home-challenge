# Agent CLI

- Agents run the CLI from a checkout with nothing but Node 24, as `node apps/cli/bundle/resend-challenge.mjs …` from the repository root. `pnpm resend-challenge …` runs `src/cli.ts` directly and is the development path: it reflects edits without a rebuild.
- `bundle/resend-challenge.mjs` is a committed single file with the CLI, `libs/api.client`, `libs/api.routes` and all their npm dependencies, built by Rolldown (`rolldown.config.ts`) in this package's `turbo:build`. `pnpm build` and `pnpm validate:fast` regenerate it; commit it with the change that altered it. Never edit it by hand: resolve a merge conflict in it by running `pnpm build`.
- Its process tests in `test/` spawn the bundle (so `turbo:test` depends on this package's `turbo:build`) against a `node:http` API stub (`useApiStub()` in `test/api-stub.ts`) and pass it its whole environment, so `RESEND_CHALLENGE_TOKEN` and `RESEND_CHALLENGE_API_URL` never leak in. `runCli()` sets `RESEND_CHALLENGE_TOKEN` to a test token unless a test overrides it, or unsets it with `undefined`.
- `RESEND_CHALLENGE_TOKEN` is required: the Agent token is a Worker secret that is never committed, so the CLI has no fallback token. Its production URL in `src/production.ts` must equal `PUBLIC_BASE_URL` in `apps/cloudflare-worker/wrangler.jsonc`.
